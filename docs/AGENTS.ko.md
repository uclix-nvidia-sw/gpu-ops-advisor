# AI Agent 컨텍스트

이 저장소의 팀 공통 지침 원본은 [루트 CLAUDE.md](../CLAUDE.md)에서 관리합니다.

이 저장소를 살펴보거나 수정·테스트하거나 문서를 작성하기 전에 `CLAUDE.md`를 읽고 따릅니다. 해당 문서의 적용 범위와 더 하위 디렉터리의 `CLAUDE.md` 재정의도 적용됩니다. 공통 지침의 한국어 번역은 [CLAUDE.ko.md](CLAUDE.ko.md)에서 볼 수 있으며, 영어 `CLAUDE.md`를 기준으로 합니다.

이 문서는 [루트 AGENTS.md](../AGENTS.md)의 한국어 참고용 번역입니다. Agent가 읽는 시작 지침 파일은 루트의 영어 `AGENTS.md`를 사용합니다.
