# 기존 O계열 보고서 흐름

이 폴더의 [상세 흐름](detailed-workflow.md)은 기존 O계열 보고서의 query+CPC 계획·병렬 수집을 설명한다. 신규 기본 `report-aggregate-v1`은 [집계 보고서 계약](../../specs/ops-agent/aggregate-report-v1.md)을 따른다. 두 경로의 분기와 실행 안내는 [Ops README](../../../ops-agent/README.md)가 관리한다.

기존 경로는 의존성·예약 예산·독립 Observation·취소 회수와 코드 통계·문장 ID 편집을 사용한다. 자유 생성형 조언과 추가 관측 라운드를 구현된 기능으로 해석하지 않는다. 검증 범위는 [Agent QA](../../../agents/QA.md)를 따른다.
