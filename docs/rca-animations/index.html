점검 위치 애니메이션 · 14종 검토

SXM(예시) 8U ↔ PCIe(예시) 4U · 같은 점검 주제를 좌우로 비교

점검 영역 정지 화면

그림과 적용 매핑을 함께 검토하세요. XID 28개 · SXID 92개 · 컴포넌트 runbook 11개가 조건부 후보입니다. 여러 그림에 중복되는 항목이 있어 카드별 수를 더하지 않습니다.

물리 점검이 필요한 사건에서 장착 형태·실제 구조를 확인한 뒤 선택합니다. 테두리는 확인할 부품군 전체이며 고장 위치·장치 번호가 아닙니다. 그림이 필요 없는 항목은 제외했습니다.

적용 조건

  • GPU 자체 또는 GPU–호스트 PCIe 경로의 물리 점검이 필요한 경우. 28개 XID는 자동 삽입 목록이 아닌 후보다.
  • 63·156·162의 복구/상태 기록만 있는 경우와 단순 조회 실패는 생략한다. PERSISTENCE-MODE는 GPU lost/reset-required 등 점검 분기만 해당한다.
  • NVLink는 GPU 측 점검 시 사용한다. SXID 5개는 S2 점검에 더해 연결 상대 GPU도 확인해야 할 때만 S1을 추가한다.

적용 조건

  • 실제 NVSwitch가 있고 스위치 영역의 물리 점검이 필요한 경우. XID·DCGM-NVLINK에서는 스위치 측 점검 근거가 있을 때만 추가한다.
  • SXID 92개는 후보다. 열 이벤트 종료·인터럽트·FM 설정 확인 등 위치 안내가 불필요한 경우는 생략한다. SXM이라는 이유만으로 모든 제품에 SXID를 적용하지 않는다.
