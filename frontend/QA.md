# Frontend 검증 범위

화면 동작은 [README](README.md), API는 [Backend 계약](../backend/API.md), 검사 명령은 [Frontend 규칙](../.claude/rules/frontend.md)을 따른다. 이 문서는 유효한 검증 근거와 미검증 범위를 유지하며 작업별 실행 일지를 누적하지 않는다.

CI 명령: `npm ci --ignore-scripts`, `npm run format:check`, `npm test`, `npm run build` (`frontend/`, Node 24). 날짜별 통과 수는 당시 revision의 근거이며 현재 전체 검사 수가 아니다. 기존 큰 번들 경고는 남아 있다.

## 남은 검증

- 최신 배포에서 정상·빈 상태·실패·partial·구 결과를 실제 API와 대조한다.
- 실제 저장 결과의 원인 수준과 모델 거절/수정 기록이 화면에서 혼동되지 않는지 확인한다.
- 큰 evidence·긴 보고서의 조회/표시와 다운로드, 좁은 화면·키보드 접근을 해당 변경 범위에서 확인한다.
- Runbook 지침 표시와 발행된 revision의 내용을 대조한다. 정적 렌더 검사는 LLM 분석의 적절성 검사가 아니다.

이전 브라우저·접근성·기능별 실행 조건은 [정리 전 검증 이력](https://github.com/uclix-nvidia-sw/gpu-ops-advisor/blob/f7bed6c594dc44a4b1d053bc8b60e2761c0b7f0c/frontend/QA.md)에 있다. 이번 문서 통합은 해당 검사를 재실행하거나 운영 배포를 확인한 것으로 해석하지 않는다.
