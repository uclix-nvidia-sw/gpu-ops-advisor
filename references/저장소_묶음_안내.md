## 경로와 원문 보존

저장소의 Markdown은 GitHub에서 열 수 있도록 경로를 정리한 **열람본**입니다. 개인 PC의 C:/ 경로는 포함 파일의 상대경로로 바꾸고, 원래 `:줄번호`는 GitHub의 줄번호 링크로 연결합니다. 이름에 공백이 있으면 URL 인코딩합니다. 이 처리로 기능·산식·API 계약은 바꾸지 않았습니다.

출처 보관본의 옛 상대경로는 원래 문서 위치를 기준으로 해석했습니다. Downloads에서 사라진 팀원 기록 3개는 기존 manifest의 SHA-256과 일치하는 로컬 고정본으로 연결했습니다. 외부 DSX Exchange 파일은 로컬에서 확인한 원본 커밋 `cf933149bad9e0f96722ae2c4b013f4f91ec0570`의 GitHub 링크를 사용합니다. 외부 저장소 자체는 포함하지 않습니다.

| 구분 | 확인 위치 |

| 경로 변경 전 문서·메모·구조도 원문 | [원문 보존 ZIP](경로변환_전_원문.zip) |

기존 원문 목록의 `original_path`는 작성 당시 출처 식별 정보입니다. 현재 열람 경로로 사용하지 않습니다. 경로를 변환한 파일의 실제 지문은 이 묶음의 `repo_sha256`, 변환 전 지문은 `original_sha256`으로 구분합니다. 원래 지문·PDF·ZIP은 당시 자료를 검증하기 위해 보존합니다.

과거 문서의 명령 예시·설치 경로·검증 기록은 당시 환경의 기록입니다. 현재 자료의 진입점은 [루트 README](../README.md)입니다. 삭제한 PDF 편집·시안 검사·캡처 도구는 과거 Git 고정본으로만 참조하며 현재 실행 안내로 취급하지 않습니다.
