실제 수집 확인 범위를 증명하는 CPC-2 작업 기록과 GPU 메트릭 대조 목록은 docs/evidence에 보존한다. 원문 성격·기록 날짜를 표시하고 새 개발 기준과 구분한다. 그 밖의 과거 자료는 Git 이력에서 조회한다. 정리 전 tracked 기준 커밋은 `84c01c023f8b307fa6e8af41d891d52ec8d25730`이다. 커밋되지 않았던 중간 구조도는 현재 확정본으로 대체했다.

루트 README, docs/README, SUMMARY, frontend README/QA를 새 기준으로 연결한다. 기존 Frontend의 Assistant·직접 RCA·역할 데모는 코드에 남아 있으며 07의 후속 구현 대상이다. 이 문서 작업에서 제거했다고 주장하지 않는다.
