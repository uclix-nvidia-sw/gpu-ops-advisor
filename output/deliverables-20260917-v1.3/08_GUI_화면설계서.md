# 08. GUI 화면설계서

버전 1.3 · 기존 DESIGN 05 캡처를 대체하는 현행 화면 계약. 구현 완료 화면이 아니다.

## 공통 화면 틀

좌측 메뉴·상단 CPC/Namespace 필터·기간/시간대·본문을 둔다. 채팅/Assistant·프로필 역할 전환·수동 RCA 실행 버튼은 없다. 상단에 데이터 기준 시각과 부족/오류를 표시한다. 사건/잡/결과의 ID가 다른 경우 모두 연결한다.

| 화면 | 필수 내용 | 행동 | 빈 상태·검수 |
|---|---|---|---|
| S01 대시보드 | 사건 현황·관측 품질·최근 보고서·큐 대기 | 사건/보고서/작업 상세 이동 | 지표 없음과 유효 0 구분 |
| S02 장비/GPU | cluster·Node·GPU UUID·모델·현재 상태/시각 | 필터·추이·관련 사건 보기 | 매핑 미확인을 미할당으로 표시 금지 |
| S03 작업 연결 | Pod UID·배치·GPU 관계·활동 각각 표시 | 관련 장치/사건 조회 | bound Pending과 unbound 구분 |
| S04 관측 품질 | 필수 입력·공동 관측률·신선도·미확인 범위 | 근거·대상별 부족 원인 조회 | 분모 미확인은 null+사유 |
| S05 RCA 사건 목록 | 사건 시각·대상·심각도·state·RCA job/result 상태 | 사건 열기·검색 | '새 조사' 없음, 사건 없으면 알람 연동 상태 안내 |
| S07 사건 RCA | 원문·당시/현재 관계·목적별 결과·후보/반박·권고·근거·한계 | 검토/실제 조치 기록·참조 이동 | 분석 대기와 원인 미확정 구분, 재분석 버튼 없음 |
| S08 보고서 목록 | 주제·분석 기간·생성 경로·상태 | 즉시 요청/정기 일정/결과 이동 | 첫 보고서 요청 안내 |
| S09 보고서 요청 | scope·완료 기간·시간대·O01~O11·group_by·선택 비교/조치 | 입력 검증 후 접수 | 슬롯 부족도 정상 접수 뒤 대기 |
| S09 일정 목록/상세 | 빈도·시간대·예정일·revision·next_run·발생 목록 | 생성·수정·일시중지/재개 | pending/accepted/missed/failed 구분 |
| S10 보고서 결과 | 주제별 수치·분모·단위·근거·품질·설명 상태 | HTML/CSV·의도적 새 보고서 요청 | blocked 주제만 사유, 독립 결과 유지 |
| S11 작업 이력 | kind·status·queue_reason·stage·attempt·deadline·결과 참조 | 보고서만 취소/기술 재시도, 전체 상태 조회 | RCA는 읽기 전용, 자원 변경 없음 |
| S12 지식 | 호환 조건·출처·revision·검토/발행 상태 | 초안·검토·발행/폐기 | 임의 실행 코드 입력 없음 |
| S13 모델 | endpoint 프로필·모델/엔진·검사 revision | 등록·수정·연결 검사 | 비밀 원문 표시/저장 없음 |
| S14 모델 지정 | rca/report → 모델 revision | 허용 모델 선택 | assistant 라우팅 없음 |
| S15 연결 | CPC별 기존 관측 경로·query/parser·검증 상태 | 등록 설정 조회/수정 | 미검증을 연결 완료로 표시 금지 |

## 주요 흐름

RCA는 알람 → 사건 생성 → RCA 큐 → Agent 처리 → S05/S07 조회다. 화면에서 새로운 RCA를 생성하지 않는다. 실행 대기 중에는 사건·원문을 먼저 조회할 수 있다.

즉시 보고서는 S08 → S09 입력 → 202/job_id → S11 진행 → S10 결과다. 정기 보고서는 S09 일정 → Backend occurrence → 동일 보고서 큐 → S10 결과다. 일정 발생 이력과 job 실행 이력을 따로 연결한다.

## 상태 문구

| 서버 상태 | 문구·행동 |
|---|---|
| queued + capacity_wait | 처리 자원을 기다리는 중. 요청은 저장됨 |
| queued + worker_unavailable | 실행 Agent를 기다리는 중. 운영 상태 확인 |
| running | 처리 단계·시작 시각·마감 표시 |
| retry_wait | 일시 오류로 재시도 대기, 기존 job 유지 |
| succeeded + partial/blocked | 처리 완료. 일부/전체 분석 근거 부족, 상세 이유 제공 |
| narrative_status=failed/omitted | 설명 생성 실패/생략, 유효 수치·근거는 표시 |
| failed/cancelled/expired | 종료 사유·시도 이력, 가능한 보고서 명령만 표시 |

## 폐기 화면과 검수

S06·S07B·S16은 폐기한다. 직접 조사 링크·대화 맥락·사용자 권한 선택을 새 설계에 남기지 않는다. 기존 시안 이미지 대신 본 표와 07을 구현 기준으로 사용한다. T28/T29와 키보드·320px·새로고침·출력 일치 시험을 수행한다.
