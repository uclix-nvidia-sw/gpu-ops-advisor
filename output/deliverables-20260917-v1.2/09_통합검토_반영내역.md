## 변경하지 않는 의미

공통 Assistant를 Chatbot Agent라는 독립 모듈로 분리하지만 RCA와 보고서의 전문 업무를 복제하지 않는다. 모델 라우팅 역할 키 `assistant`는 기존 API 호환을 위해 유지하며 module_id=`chatbot`과 대응한다. R/O, 계산 산식, 5%·60분·95%·90% 기준, 실제 조치의 운영자 책임은 유지한다.

Gateway·사내 추론·관측 저장소는 기존 역할을 유지한다. 브로커·벡터 DB·모듈별 PostgreSQL 서버는 새 필수 구성으로 추가하지 않는다. 공유 DB이므로 스키마와 공통 코드 호환은 여전히 조율한다.
